DOCUMENTATION & API

Universal API Reference

Engineered for immediate developer ergonomics and AI code generation (llms.txt).

animate(target, keyframes, options?)

Compiles CSS properties, independent transforms, and spring physics directly into native WAAPI element.animate() keyframe effects.

target string | Element | Element[] CSS selector, DOM node, or collection.
keyframes AnimatableProperties Object of properties with target values or [from, to] tuples.
options.spring 'snappy' | 'bouncy' | 'smooth' | SpringConfig Analytical ODE spring configuration.
options.stagger number Delay offset between sequential elements in ms.
Returns: AnimationHandle with play(), pause(), reverse(), and .finished Promise.
Interactive Live Sandbox 
animate('#demo-target', {
  x: [0, 180],
  rotate: [0, 180],
  scale: [0.8, 1.2],
  borderRadius: ['12px', '50%']
}, {
  spring: 'bouncy'
});
0G

timeline(options?)

GSAP-tier timeline sequencer. Flattens chained animations into exact start delays for WAAPI instances synced to document.timeline.

.add(target, keyframes, options) Queues an animation step with optional position parameter at.
options.at number | string 1.5 (absolute), "-=0.3" (relative), "<" (with previous).
Code Example 
const tl = timeline({ delay: 100 })
  .add('.header', { y: [30, 0] }, { spring: 'snappy' })
  .add('.hero',   { scale: [0.8, 1] }, { at: '<' })
  .add('.cards',  { opacity: [0, 1] }, { stagger: 50, at: '-=0.2' });

await tl.play().finished;

solveSpring(config?)

Exact closed-form ODE solver for damped harmonic oscillators. Solves underdamped, critically damped, and overdamped differential equations.

stiffness (k) number (default: 100) Restorative force constant.
damping (c) number (default: 10) Viscous energy dissipation coefficient.
mass (m) number (default: 1) Payload inertia mass.
Code Example 
const solver = solveSpring({
  stiffness: 300,
  damping: 20,
  mass: 1.2,
  velocity: 5
});

const { position, velocity } = solver(0.15); // state at 150ms

autoMorph(container, options?)

AI-native layout transition primitive. Uses ResizeObserver and batched WAAPI height morphing to eliminate scroll jumping during LLM token streaming.

Streaming Setup 
const morph = autoMorph(chatContainer, {
  spring: 'snappy',
  threshold: 2 // batch layout changes > 2px
});

// In your LLM stream callback:
onToken((token) => {
  messageEl.textContent += token;
  // Container morphs fluidly at 120 FPS on the GPU!
});

animateText(el, options) & scrambleText(el, options)

Kinetic typography suite with 8 cinematic presets, strict WCAG accessibility (aria-label wrapper), and hacker terminal character decoders.

Presets 
animateText('#hero', {
  preset: 'flip-3d', // 'mask-up' | 'blur-in' | 'wave' | 'glitch'
  spring: 'bouncy',
  stagger: 35
});

scrambleText('#terminal', {
  charset: 'katakana', // 'hex' | 'binary' | 'ascii'
  duration: 800
});

magnetic(target, options?)

Inverse-square spatial cursor attraction. Pulls elements toward pointer coordinates with velocity injection and spring damping.

Usage 
magnetic('.btn-magnetic', {
  strength: 0.35,
  radius: 120,
  spring: 'snappy'
});
